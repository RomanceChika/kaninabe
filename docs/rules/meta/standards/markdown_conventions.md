# Markdown 記述規約

`docs/rules/` 配下の文書を書くときの Markdown の書き方である。**目的は、どのビューワーでも同じように読めることと、見出しの構造が機械で扱えること**の 2 つに絞ってある。

## コードブロック言語指定

- **すべてのコードブロックに言語を指定する。** 言語の無いフェンスはシンタックスハイライトが効かず、何のコードなのかが本文の文脈頼みになる
- 使う言語は次のとおり

| 指定 | 用途 |
|---|---|
| `bash` | シェルコマンド |
| `yaml` | フロントマター、仕様の YAML |
| `sql` | マイグレーション、クエリ |
| `typescript` | 実装のコード例 |
| `text` | その他のリテラルテキスト(仕様書の例・出力例・フォーマット例) |

- **`markdown` の指定を禁止する。** 代わりに `text` を使う(理由は下記)

## 禁止事項

### ```` ```markdown ```` を使わない

理由は 2 つある。

1. **ビューワーによっては正しくレンダリングされない。** Markdown の中の Markdown をどう扱うかは実装依存である
2. **コードブロックのネストを引き起こす。** Markdown の例には高い確率でコードフェンスが含まれるため、次の禁止事項に抵触する

### コードブロックをネストしない

コードフェンスの中にさらにコードフェンスを書かない。**Markdown 仕様の未定義動作であり、ビューワー次第で表示が崩壊する。**

ネストが必要に見えるときは、**内側のコードブロックを 4 スペースのインデントにする**。インデントによるコードブロックはフェンスを使わないので、外側のフェンスと衝突しない。

### 執行者について

この節と上の「コードブロック言語指定」に**機械の執行者は無い**。`npm run verify` の M 群が見るのはフロントマター・id・参照・リンク・H2 の構造であり、コードフェンスの中身には踏み込まない。守るのは書き手の側であり、レビューで指摘する対象である。

## データテーブル仕様書の記述規則

カラム定義の表を持つ仕様文書(`doc_type: data_table`)に対する規則である。

- **カラム定義テーブルは、第 1 ヘッダセルが「カラム名」である場合にのみ**、機械的な突合の対象になる。この目印が無い表は自然文の一部として扱う
- **対象外の表:** 値の説明テーブル(`| 値 |` で始まるもの)、構成パターンのテーブル、`## カラム値詳細` の中の補足テーブル
- **略記法:** 同じパターンで連番になる多数のカラムは、`〜`(波ダッシュ)を使った略記行で 1 行にまとめてよい(`regulation_01_flg〜regulation_61_flg` のような形)。`/` を使うスラッシュ記法(`scope_e/j/c`)も同様に展開する。突合する側は略記を展開したうえで個別のカラムと照合する

**現構成にこの規則の適用対象は無い。** `data_table` の文書はまだ 1 本も無く、置き場所だけが [placement_policy](./placement_policy.md) に予約されている。テーブルの定義は現在 `docs/specs/domain/{aggregate}/entity.md`(`entity_spec`)が `table` と `fields` で持っており、その本文の表は `<!-- AUTO-GENERATED -->` の生成物である —— **生成物は手で書かないので、この節の書き方の規則は当たらない。** 略記を展開する検査器も現時点では存在しない。`data_table` を実際に使い始めるときは、この節の規則と、それを執行する検査を同時に用意する。

## 見出し

- **見出しのレベルをジャンプしない。** H2 の次に H4 を置かない(H2 → H3 → H4 の順に下げる)。飛ばすと、見出しから組み立てられる目次が構造を失う
- **H2 の集合は、解決されたテンプレートの H2 と一致させる。** これは `npm run verify` の **M5** が執行する(現在は warning)
  - ただし一致の厳しさはテンプレート側の宣言で変わる。**既定は closed** でテンプレートに無い節も咎められるが、`h2_policy: open` を宣言したテンプレート(現状は directory_guide のみ)の配下では、必須節の欠落と「節がひとつも無いこと」だけを見る。詳細は [template_policy.md](./template_policy.md)
  - 見出しレベルのジャンプ自体に執行者は無い。M5 が見るのは H2 だけである
- **1 つの文書に H1 は 1 つだけ置く。** 本文の途中に 2 つ目の H1 を置かない。文書の題は 1 つであり、並列に見えるものは H2 に下げる
