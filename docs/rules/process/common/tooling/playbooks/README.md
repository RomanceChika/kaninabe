**空でも README を残し、未整備であることを明示する。** 行を消して一覧ごと無くすと、「まだ書いていない」のか「そもそも要らない」のかが読み手に伝わらない。この箱については前者である。

書き起こすべき手順の筆頭は「検査器を1本足す手順」である。検査器は `legacy/spec-tools/lib/docs/verifiers/` の M 群から V / A / Q / S / G / U 群まで広がっており、追加は既に何度も行われている。にもかかわらず手順が文書化されていないので、次に足す人は既存の検査器を読んで真似るところから始めることになる。

文書を足すときは同階層の [template.md](./template.md) に従う。書き方の基準(ツールコードの品質規約)は [../standards/scripts-code-quality.md](../standards/scripts-code-quality.md) が正であり、手順側からはそこへリンクする。
