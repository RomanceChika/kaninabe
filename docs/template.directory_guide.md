# {ディレクトリ名} — {ひとことで言うと何の置き場か}

そのディレクトリの**責務**を 1〜3 行で書く。「ここに何を置くか」「置かないもの（どこに置くか）」まで書けると、
迷った人がこの README だけで置き場所を決められる。配下に文書を足すときに従うテンプレートの所在も、
ここか `## テンプレート` で案内しておく（[template_policy](./rules/meta/standards/template_policy.md)）。

**このテンプレートの使い方**（実文書には残さない）:

- **入口は README.md ひとつ**。AI 向け・人間向けでファイルを分けない（[ADR-0005](./rules/decisions/common/ADR-0005-single-entry-point.md)）。
- **節はすべて任意**であり、下の一覧は「よく使う節の語彙」である。`h2_policy: open` を宣言しているため、
  ディレクトリ固有の節（例: `## 先送りの宣言`、`## 新しいルールを増やすとき`）を足しても M5 は咎めない。
  逆に、**節がひとつも無い README は M5 が警告する**（案内になっていないため）。
- 迷ったら「**このディレクトリに何があるか**（一覧 / 構成）」と「**次にどこを読むか**（関連 / 参照するもの）」の
  2 つだけ書けばよい。他は必要になったときに足す。
- 仕様・規約の**中身**は README に書かない。書きたくなったら、それは別ファイルに切り出す合図
  （[doc_types.md「README.md のルール」](./rules/meta/standards/doc_types.md)）。

## 目的（任意）

## 構成（任意）

|------|------|

| 文書 | 内容 |
|------|------|

## 参照するもの（任意）

## 関連（任意）
