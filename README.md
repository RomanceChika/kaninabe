# kaninabe

A spec-driven framework for web apps: the specification is the source of truth, and verification, documents, implementation parts and tests are derived from it.

**Status: 0.x, not yet stable.** Interfaces, package names and the repository layout may change without notice.

This is provided as-is, under the MIT license (see `LICENSE`). There is no commitment to maintenance or support, the repository may not stay public, and use is at your own risk. Forks are welcome.

Development happens on the `dev` branch until 1.0; `main` only receives reviewed releases.
