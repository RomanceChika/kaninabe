# {タイトル}

この手順が何をするものかを 1 行で書く。

## 目的

- この手順・プロセスで何を達成するかを箇条書きで書く。

## 前提条件（任意）

あるものだけ書く。無い項目は行ごと落とす。

- **事前に読むもの**: 参照すべき文書へのリンク。
- **入力**: この手順を始める前に存在していなければならないもの(仕様書・チケットなど)。
- **環境条件**: 実行に必要な環境(ローカル DB が起動していること、など)。

## 全体の手順・流れ（概要）

`0.` から始まる番号付きで、手順名だけを並べる。

0. {手順 0 の名前}
1. {手順 1 の名前}
2. {手順 2 の名前}

手順の本体は H3 で展開する。手順数だけ繰り返す。

### 手順N: {名前}（必要に応じて繰り返し）

- **目的**: この手順で何が終わるか。
- **実装場所・作業内容**: どこを触り、何をするか。
- **確認事項**: 次へ進んでよいと判断する条件。
- **実行コマンド**(あれば): 実行するコマンド。
- **注意点**(あれば): 踏み抜きやすい落とし穴。

## 関連ドキュメント

- この手順が依存する文書へのリンクを並べる。

## 詳細（任意）

ファイル固有の参考情報を H3 でまとめる。対象になるのは、インストール手順・コマンド一覧・使用例・CI/CD での活用など、手順本体に混ぜると流れが読めなくなるものである。
