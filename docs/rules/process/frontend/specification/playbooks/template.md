この手順で何を達成するかを書く。**生成器や Skill など機械が読む台本になりうる場合は、その旨をここに明記する。** 手順書を人間向けの読み物に閉じてしまうと、`npm run generate` や `.claude/skills/` の側が同じ段取りを別の言葉で持ち直すことになり、正が 2 つに割れる。
